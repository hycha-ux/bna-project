## 모델 라우팅 — **셀카 = GPT** (2026-09-08 성연서님 확정)

정본은 `config/providers.yaml` 의 `default_provider` **한 곳**이다. 코드에 벤더 이름을 다시 박지 마라
(`selftest.py` ② 가 재발을 막는다). CLI 플래그(`--gen/--edit/--qa`)를 주면 그게 이긴다.

| 모드 | gen | edit | qa |
|---|---|---|---|
| selfie | **openai(gpt-image-2)** | openai | openai |
| clinical | gemini | gemini | gemini |

근거는 실측이다 — 프레이밍 축(코 아래만·한쪽 볼) 준수율 **GPT 4/4 vs Gemini 0/4**.
Gemini 는 부분 크롭 지시를 통째로 무시하고 늘 얼굴 전체를 그려 레퍼런스(후기 앱) 룩이 안 나온다.
셀카는 gen·edit·qa 셋 다 GPT 라 **키 하나로 셀카 파이프가 끝까지 돈다**(중간에 다른 벤더를 끼우지 않는다).

⚠ 함정 셋:
- **`OPENAI_API_KEY` 가 없으면 셀카 배치는 시작 즉시 `NotConfigured` 로 선다.** 조용히 다른 모델로 안 떨어진다(의도).
- **`aspect` 는 `providers.yaml` 의 `aspect_size` 에 있어야 한다.** 없으면 예외다 —
  임의 폴백을 넣지 마라(세트 안에서 비율이 갈리면 전후 비교가 깨진다). 새 비율은 gpt-image-2 제약
  4종(두 변 16의 배수·긴변 ≤3840·비율 ≤3:1·총 픽셀 65.5만~829만)을 함께 만족해야 하고 `selftest.py` ④ 가 검사한다.
- **`pricing.yaml` 의 openai 단가는 미실측 추정치다.** `--estimate` 는 참고치이지 예산이 아니다.

## 검수 · 드라이브 · 학습 (2026-09-08 성연서님 지시)

지시 넷을 한 고리로 묶었다: 워딩 명확화 → 클릭이 실제로 먹히게 → 채택=드라이브 등록/제외=미등록
→ 제외 사유가 다음 프롬프트를 고치게.

### 워딩 (정본 = `web/index.html` 의 `PICK` 한 곳)

`선택`/`제외`만으로는 눌렀을 때 **무슨 일이 생기는지**가 안 보였다 → 결과를 말에 넣었다.
내부 값(`pick`/`reject`)은 안 바꿨다 — 바꾸면 이미 저장된 `review.json` 과 통계 축이 갈린다.

| 화면 | 뜻 |
|---|---|
| `채택 · 드라이브 저장` | 쓰겠다. 구글드라이브 `채택본/` 으로 올라간다 |
| `제외 · 저장 안 함` | 안 쓴다. 채택본에 안 올리고, 이미 올라갔으면 내린다 |
| `판정 지우기` | 아직 안 정함. 드라이브에 안 올라간다 |

카드마다 `드라이브 저장됨 / 저장 대기 / 저장 안 함` 배지가 붙어 **지금 상태**를 말한다.
제외 사유 버튼 위엔 "누르면 제외로 넘어간다"를 적었다 — 종전엔 태그만 눌러도 조용히 제외됐다.

### 클릭이 반영 안 되던 이유 (수리 완료)

뿌리는 **클라우드 배포본이 보기 전용(쓰기 405)인데 화면이 그걸 몰랐던 것**이다.
버튼은 멀쩡해 보이고, 누르면 서버가 405 를 주고, `onAct` 에 try/catch 가 없어 조용히 삼켜졌다.
같이 고친 것:

1. `/api/config` 가 `readonly: true` 를 준다(cloud 전용) → 화면이 배너를 띄우고 버튼을 잠근다
2. `save()` 에 try/catch — **실패하면 화면을 이전 상태로 되돌리고** 이유를 토스트로 낸다
3. 낙관적 반영 제거 — 서버 응답을 정본으로 덮어쓴다(눌렀는데 새로고침하면 원복되던 것)
4. 연타 차단 — 같은 사진의 저장이 끝나기 전엔 안 받는다(`SAVING`)
5. 메모 유실 수리 — 종전엔 **입력칸을 한 번 클릭해야** Enter 가 걸렸고 blur 하면 날아갔다.
   이제 렌더 시점에 바로 걸고 Enter·blur 둘 다에서 저장하며, **입력 중엔 카드를 갈아끼우지 않는다**
6. `api()` 가 JSON 아닌 오류 응답(502·HTML)도 말이 되게 처리

### 드라이브 레인 (정본 = `ops/drive-backup.mjs` 의 `targetsFor`/`planLanes`)

```
<백업 폴더>/채택본/<시술>_<종류>/<배치>_<아이템>_<파일>.jpg   ← 채택한 사진만
<백업 폴더>/_원본안전망/outputs/...                      ← 전량 사본(PC 사망 대비)
<백업 폴더>/_제외됨/...                                      ← 채택했다 제외한 사진
```

- **채택본에는 제외·미검수가 절대 안 들어간다.** 사진 파일만 올린다(meta.json 같은 부속 제외).
- **내릴 때 지우지 않는다 — 부모만 `_제외됨/` 으로 바꾼다.** 이 백업은 삭제 권한을 안 쓰고
  (회귀가 `DELETE`·`trash` 호출 부재를 단언한다), 오판으로 제외를 눌러도 파일이 남는다.
- ⚠ **레인이 둘인 이유**: `채택본` 은 창고(지시 그대로)이고 `_원본안전망` 은 2026-09-08
  어제 지시로 만든 재해 대비다. 목적이 달라 합치지 않았다. 전량 레인이 필요 없으면
  `--no-full` 이고, 그러면 **제외·미검수 사진은 이 PC 에만 남는다**(그게 맞는지는 사람 결정).
- 즉시 반영 = `src/bna/drivesync.py`. 채택/제외를 누르면 그 **한 장만** `--item <배치>/<아이템>`
  으로 백그라운드 처리한다(전량 스캔은 23:00 정기 회차). 키가 없으면 조용히 대기(exit 3).

### 제외 사유 → 프롬프트 (정본 = `src/bna/lessons.py` + `config/prompts/avoid.yaml`)

되먹임 고리 네 칸. 하나라도 빠지면 학습이 아니라 그냥 기록이다.

1. **쌓기** — 검수할 때마다 사유·조건·메모를 `outputs/lessons.jsonl` 에 한 줄(append-only).
   제외뿐 아니라 **모든 판정**을 적는다. 제외만 적으면 나중에 채택으로 바꿔도 원장엔 제외가
   마지막 줄로 남아, 이미 고친 실수를 계속 금지문으로 붙인다.
2. **고르기** — 최근 14일에 **2회 이상** 찍힌 사유 상위 3개만. ⚠ 전부 붙이지 않는다:
   프롬프트가 길어지고 이미지 모델은 부정문의 단어 자체에 끌려 오히려 그 실수를 부른다.
3. **붙이기** — `build_prompts` 가 `{avoid}` 자리에 넣는다(before/after 따로).
   겸해 제외가 **3회 이상 몰린 조건값**은 다음 배치에서 추첨 확률을 0.25 배로 낮춘다
   (`plan_batch(avoid_weights=)`). ⚠ **0 으로 빼지 않는다** — 최소 1 은 남긴다.
   빼 버리면 그 조건이 나중에 좋아졌는지 확인할 길이 영영 사라진다.
4. **재기** — 규칙마다 `since` 가 있어 도입 전/후 제외 건수를 갈라 본다(학습 탭 성적표).
   `avoid.yaml` 은 `config/` 안이라 고치면 `prompt_version` 이 자동으로 바뀐다 = 전후 경계.

⚠ **한글 자유 메모는 자동으로 프롬프트에 안 들어간다.** 오타·모순·환자 정보가 섞이고
프롬프트 인젝션 통로가 된다 → 학습 탭에서 사람이 **영어 한 문장으로 다듬어 「규칙으로 승격」**
해야 `avoid.yaml` 의 `custom` 에 들어가고 그때부터 매번 붙는다.

회귀 = `selftest.py` ⑰(8종) + `ops/drive-backup-tests.mjs`.

디자인: 레이아웃은 네이버 부동산 대시보드 레퍼런스(Behance 194113213) 구조 — 왼쪽 아이콘 레일 + 라벨 사이드바, 상단 바(제목·검색·알림·프로필 메뉴), 카드형 콘텐츠(KPI 행 + 차트 + 우측 목록). 회색 토큰은 디자인 자동화 툴(`AI-Tools/platform/common/_base-template.html`)과 동일. 브랜드색은 온리프 네이비(`--primary` #1F3A5F). 버튼·배지·칩은 SEED Design 레시피(`web/vendor/seed/`, `seedify()` 자동 매핑). 워딩은 간결한 용어(생성·작업·통과·장당 비용, 조건값 한국어).

## 검수는 클라우드에서도 된다 (2026-09-08 성연서님 "나는 지금 PC에서 진행하고 있거든!")

**무엇이 문제였나.** 클라우드가 *모든* 쓰기를 405 로 막고, 화면엔 "생성·검수·내보내기는
사무실 PC에서 진행합니다"라고만 떴다. 두 가지가 틀렸다:
①"사무실 PC"는 보는 분이 PC 앞에 계실 때 **자기 PC** 를 가리키는 말로 읽힌다.
②"왜"가 없어 고장으로 읽힌다. 게다가 문구만 고쳐도 소용없었다 — 로컬 서버는 꺼져 있었고
(실측 `localhost:8765` 무응답) 사진은 이 PC 에만 있어, **검수할 방법이 아예 없었다.**

**무엇을 고쳤나.** 막을 이유가 있는 건 돈·시간이 드는 *생성*과 디스크를 쓰는 *내보내기*뿐이다.
검수는 판정 한 줄이라 열었다.

```
클라우드에서 누름 → Blob `reviews/<배치>__<아이템>.json`      (여기가 그 순간의 원장)
화면              → 스냅샷 + 이 오버레이를 겹쳐 봄            (10분 배치를 안 기다린다)
사무실 PC 10분 배치 → 흡수 → 로컬 API `/api/review` 로 저장    (드라이브·학습 훅이 같이 탄다)
                   → 스냅샷 업로드 → 그다음에 흡수분 삭제
```

- ⚠ **순서를 바꾸지 마라.** 삭제를 스냅샷 업로드 앞에 두면, 그 사이 화면이 옛 스냅샷을 읽어
  방금 누른 판정이 사라져 보인다.
- ⚠ **흡수는 파일에 직접 쓰지 않고 로컬 API 를 거친다.** 파일에 바로 쓰면 드라이브 등록과
  프롬프트 학습이 조용히 빠진다.
- ⚠ **충돌은 `updated_at` 이 큰 쪽이 이긴다** — 양쪽 다 사람이 누른 값이다. PC 에서 방금 고친 걸
  클라우드의 옛 판정이 덮으면 안 된다.
- 화면 잠금 축이 둘로 갈렸다: `RO()`=검수 잠김(저장소가 끊겼을 때만) / `NO_CREATE()`=생성·내보내기.
  배너는 "여기서 되는 것 ✅ / 안 되는 것 🚫 + 왜"로 바꿨고, 생성 버튼에도 미리 적는다
  (눌러 보고 알게 하지 않는다).
- 정본 = `cloud/lib/reviews.mjs` 하나(겹치기·충돌 판정을 다른 데서 다시 쓰지 마라).
  회귀 = `node cloud/review-tests.mjs`(20종).

## 대시보드 (클라우드 · 검수 가능 / 생성·내보내기는 생성 컴퓨터)

https://onlif-bna.vercel.app — Vercel 프로젝트 `bna-dashboard`(hycha-ux 계정), 비밀번호 게이트.

**왜 보기 전용인가.** 생성은 한 장에 수십 초~수 분이 걸리고 유료 API를 부른다. Vercel 함수는
요청 단위로 떴다 지므로 큐·워커를 얹을 수 없고, 파일시스템도 휘발성이라 `outputs/`를 둘 수 없다.
그래서 **주방(생성·큐·검수)은 사무실 PC, 진열대(보기)만 클라우드**로 나눴다. 쓰기 계열
(`/api/run`·`/api/queue/*`·`/api/review`·`/api/export`)은 클라우드에서 **405**로 막는다 —
돈 쓰는 버튼을 인터넷에 두지 않는다.

**갱신 절차 (배치를 돌린 뒤)**
```bash
node build-cloud.mjs                    # web/ → cloud/web·cloud/public (산출물, 손으로 고치지 마라)
node cloud/push-cloud.mjs --dry         # 무엇을 올릴지 확인
node cloud/push-cloud.mjs               # 스냅샷 + 이미지 → Blob
cd cloud && npx vercel --prod --yes     # 화면 코드를 고쳤을 때만 필요
```
`push-cloud.mjs`만 다시 돌리면 재배포 없이 화면 값이 바뀐다(함수가 Blob을 읽는다).

**집계 정본은 로컬 API 하나다.** push 스크립트는 `src/bna/api.py`를 띄워 그 응답을 그대로 긁어
올린다 — 클라우드에서 다시 계산하지 않는다. 두 곳에서 따로 세면 화면 둘이 조용히 갈린다.

**함정**
- ⚠ push 스크립트가 로컬 API를 직접 띄우면 `api.py`의 큐 러너도 같이 깨어난다 = 밀린 작업이 있으면
  **돈이 나간다**. 그래서 큐가 비어 있지 않으면 띄우지 않고 멈춘다(이미 8765에 떠 있으면 그걸 쓴다).
- ⚠ 스냅샷은 **이미지보다 나중에** 올린다. 먼저 올리면 화면이 아직 없는 사진을 부른다.
- ⚠ `AUTH_SECRET`이 없으면 사이트가 503으로 닫힌다(fail-closed). 생성 이미지가 사람 얼굴이라
  게이트가 유일한 방어라서, 열어 두느니 안 뜨는 쪽을 택했다.
- ⚠ 이미지는 **private Blob**이고 함수가 쿠키를 확인한 뒤에만 프록시한다. 배포본에 사진을 굽지
  않는 이유는, 구우면 지난 배포 URL에 영구히 남아 나중에 지울 수 없기 때문이다.
- ⚠ 화면 하단 배너의 "사무실 PC 기준 …" 시각이 스냅샷 시각이다. 실시간이 아니다 — 지우지 마라.
- ⚠ `cloud/web/`·`cloud/public/`은 `build-cloud.mjs` 산출물이다. 고칠 자리는 `web/`.

### 인터넷 화면에서 누른 생성이 이 PC에서 돈다 (2026-09-09 성연서님 지시)

"클라우드 화면에서 생성을 누르면 티모가 알아서 돌리는 구조" — 쓰기 버튼을 인터넷에 두지 않는다는
원칙은 그대로 두고, **주문서만 오가게** 했다. 화면은 요청을 Blob `gen-requests/<id>.json` 에 적고,
이 PC의 폴러가 1분마다 열어 가져간다. 규약 = `docs/gen-request-protocol-0909-buildy.md`(정본).

```
요청됨 ──> 받음 ──> 생성 중 ──> 완료 | 실패          (취소는 '요청됨' 일 때만, 화면에서)
 화면          여기서부터 이 PC(ops/gen-poller.mjs)
```

- 예약작업 **`TeemoBnaGenPoller`**(1분마다) · 등록 `powershell -NoProfile -File ops\register-genpoller-task.ps1`
  · 정의 덤프 `ops/task-defs/TeemoBnaGenPoller.xml` · 로그 `outputs/gen-poller.log`(할 일 없는 회차는 안 쌓는다).
- 상태 전이 규칙은 `cloud/lib/genreq.mjs` 하나가 정본이다(`canTransition`). 폴러는 그 함수만 부른다.
- ⚠ **로컬 API 를 넣을 요청이 있을 때만 띄우고, 띄운 뒤엔 죽이지 않는다.** 생성은 몇 분씩 걸리는데
  회차는 1분이면 끝나므로, 여기서 kill 하면 돈을 쓰고 시작한 배치가 그 자리에서 날아간다.
  - 예외 하나: **파이썬 코드가 바뀌었는데 옛 서버가 떠 있으면** 갈아 끼운다(큐가 비었을 때만).
    이 서버는 한 번 뜨면 며칠이고 살아 있어서, `git pull` 뒤에도 조용히 옛 코드로 돈다 — 09-09 실측:
    그날 새로 생긴 `series`(경과 시리즈 시점) 칸이 **오류 없이 통째로 무시돼** 전·후 2장이 나왔다.
  - ⚠ 갈아 끼울 때 죽이는 pid 는 `spawn` 이 준 번호가 아니라 **그 포트를 물고 있는** 번호다.
    venv 의 `python.exe` 는 진짜 인터프리터를 자식으로 띄우는 껍데기라 둘이 다르다.
  - **사람이 부르는 재시작 = `node ops/gen-poller.mjs --restart-api`**(2026-09-10). 자동 갈아
    끼우기는 *코드가 바뀌었을 때만* 걸리므로, 서버가 이상하게 굴 때 열 문이 따로 필요했다
    (종전엔 pid 를 손으로 찾아 죽였다 — 그 자리가 사고 자리다). **큐에 도는 작업이 있으면
    아무것도 안 하고 exit 2** 로 멈춘다(죽이면 그 생성이 그 자리에서 날아간다). `--dry` 로
    무엇을 죽일지 먼저 볼 수 있다. 막는 조건 정본 = `restartBlockers()`, 회귀 = 폴러 테스트 ⑤.
    ⚠ 큐 원장은 파일(`outputs/queue.json`)이라 재시작해도 작업 이력은 안 사라진다.
- ⚠ **같은 요청을 두 번 돌리면 그게 곧 돈이다.** 막는 장치가 넷 — 락 파일 · 쓰기 직전 재확인(그 사이
  눌린 취소를 여기서 흡수) · 큐 작업에 붙이는 **라벨 `genreq:<id>`**(작업 번호를 못 적고 죽어도 다음
  회차가 그 작업을 찾아 *붙인다*, 새로 넣지 않는다) · 한 회차 상한 10건. 회귀가 이 넷을 다 본다.
- ⚠ **Blob 쓰기엔 `allowOverwrite`, 읽기엔 `useCache: false` 가 있어야 한다**(09-09 실측). 앞의 것이
  없으면 두 번째 쓰기가 전부 실패해 **화면의 취소 버튼조차 한 번도 안 먹고**, 뒤의 것이 없으면 완료
  50초 뒤에도 옛 상태가 읽혀 폴러가 끝난 요청을 또 닫는다. 둘 다 `genreq.mjs` 한 곳에 있다.
- ⚠ 시뮬 배치(`kind: sim`)는 클라우드 스냅샷에 안 올라간다 — 시험은 공짜지만 완료 줄의 '결과' 버튼은
  **실제 생성**부터 의미가 있다.
