도움말

홈

전체 생성·통과·채택 현황, 시술별 통과율, 최근 작업, 진행 중 작업.

생성

시술(복수)·사진 종류·장수·목표 통과 장수·비용 상한을 정해 생성 시작. 모든 작업은 대기열로 들어가 순서대로 실행.

작업

작업 목록에서 줄을 누르면 아래에 진행·지표·탈락 사유·사진이 열림. 사진마다 채택(드라이브 저장)/제외(저장 안 함)와 제외 사유.

학습

제외 사유가 쌓여 다음 생성 프롬프트를 고칩니다. 메모는 사람이 확인해 「규칙으로 승격」해야 반영됩니다.
