# 아프터(After) 브랜드 시트 v0.6 — 2026-09-15 빌디, 연서님 확정

시각본: [docs/brand/after-brand.html](brand/after-brand.html) (브라우저로 열면 로고·파비콘·일러스트·색 표가 보인다)

## 이름
- 한글 **아프터**, 영문 **After**. 소속 표기는 "After by MediBuilder".
- 병원 이름은 로고·이름에 넣지 않는다. 온리프·르샤인·오블리브가 같은 아프터를 각자 워크스페이스로 쓴다.
- 코드·폴더·저장소 이름은 `after`. 현재 `bna` 저장소는 그대로 두고 화면·문서 제목만 바꾼다.
- 한 줄 설명: **"시술 전후, 촬영 없이 미리 봅니다."**

## 로고
- 정본: `web/assets/after-logo.svg` (연서님 제작, 둥근 덩어리 글자). 색은 `currentColor` 라 CSS 한 줄로 검정·흰색 전환.
- 흑백만 쓴다. 그라데이션·그림자·기울임·병원 색 금지.
- 글자가 안 읽히는 작은 자리(파비콘·슬랙 봇·사이드바 접힘)에는 **손그림 컷** 하나: `web/assets/favicon.png`(64) · `favicon-180.png`. 두 손 볼에 대고 반짝이는 얼굴 = 시술 후 만족한 순간.

## 뱃지 4단계 — 색이 아니라 진하기
| 단계 | 바탕 / 글자 | 뜻 | 예 |
|---|---|---|---|
| 1 블랙 | `#191919` / `#FFFFFF` | 사람이 봐야 하는 것 | 실패, 오류, 중단됨, 제외 사유 |
| 2 그레이 300 | `#D3D1CB` / `#191919` | 지금 움직이는 것 | 실행 중, 대기, 재시도 |
| 3 그레이 200 | `#E9E9E7` / `#37352F` | 끝난 것 | 완료, 통과, 채택 |
| 4 그레이 100 | `#F2F1EE` / `#6B6A66` | 그냥 정보 | 실제, 셀카형, 임상형, 테스트 |

대시보드에서는 SEED 뱃지 토큰(`--seed-color-bg-*-weak`, `--seed-color-fg-*-contrast`)을 `:root`에서 이 값으로 덮어쓴다.
막대·차트: 달성·통과 블랙, 진행 중 그레이 500, 실패 그레이 300, 빈 트랙 그레이 100. 차트 계열 5단계.

## 채택함 · 제외함 — 색 대신 형태
- 채택: 카드 2px 블랙 테두리, 사진 선명, 버튼 블랙 솔리드 + "✓ 채택함". 반대쪽(제외) 버튼은 빈 아웃라인.
- 제외: 카드 점선 회색 테두리, 사진 45% 흐림 + 흑백, 버튼 그레이 200 바탕 + 취소선 "제외함". 반대쪽(채택) 버튼은 빈 아웃라인.
- 미정: 얇은 테두리, 둘 다 빈 버튼. 썸네일 줄도 같은 규칙.
