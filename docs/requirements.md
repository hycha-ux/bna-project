# 요구사항 — 온리프 B&A 자동화

작성일: 2026-09-07 (킥오프 메모 기준)

## 목표
온리프 시술별 Before/After 이미지를 자동 생성. **사진은 리얼리티성이 강해야 함.** AI 티가 나면 실패.

## 출력 모드 (2종)

| 모드 | 용도 | 특징 |
|---|---|---|
| **후기용 (임상)** | 고객후기 / 임상 자료 | Before·After **동일 구도**. 정면·측면 고정, 배경·조명 통제, 의료 사진 톤 |
| **셀카용 (일반인)** | SNS 후기, 일반인 셀카 느낌 | 손에 든 폰 셀카 구도. 자연스러운 생활 배경 |

## 시술 목록 (우선순위 순)

1. **팔자주름** (1순위)
2. **스킨부스터 엠보** (2순위)
3. 코 프팅(코 필러/실)
4. 피부 — 스킨 퀄리티: 스킨부스터 **홍조**, **모공**
5. 리프팅
6. 필러
7. 인중

## 변주 축
매 출력마다 아래 축을 조합해 다양성 확보. 단, Before/After 쌍 안에서는 시술 부위 외 모든 요소가 **동일**해야 한다.

- 나라 (한국 / 일본 / 중국 / 동남아 / 서구권)
- 연령대 (20대 / 30대 / 40대 / 50대+)
- 성별
- 배경 (클리닉 / 집 / 카페 / 야외 / 차 안 / 화장실 거울)
- 카메라 각도 (정면 / 반측면 / 측면 / 셀카 하이앵글 / 로우앵글)
- 조명 (링라이트 / 자연광 창가 / 실내 형광등 / 야간 실내 / 역광)
- 색감 (뉴트럴 / 웜 / 쿨 / 아이폰 기본 / 갤럭시 기본 / 필터 살짝)
- 카메라 화소 퀄리티 (최신 플래그십 / 중급 / 구형폰 노이즈 / 전면카메라 저화질)

## 품질 기준 (알려진 실패 패턴)
셀카용 출력 시 반복적으로 부자연스러운 요소. 검수 단계에서 반드시 체크.

- **손가락** (가장 빈번) — 개수, 관절, 폰 쥐는 방식
- 모공 / 피부 잡티 — 지나치게 매끈하거나 패턴처럼 반복
- 솜털
- 머리카락 — 가닥 흐름, 경계
- Before/After 간 인물 동일성 (같은 사람이어야 함)
- 시술 부위 외 변화 없음 (표정·조명·각도 드리프트 금지)

## 운영 / 계정
- 계정: **BX·그로스팀 메디빌더 구글계정** 기준, 관리자급 권한 배정
- API 키 전달 예정: **GPT (OpenAI), Gemini, Higgsfield**
- 저장소: hycha-ux/bna-project (개인 깃 미사용)
