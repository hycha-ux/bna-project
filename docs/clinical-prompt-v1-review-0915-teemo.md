**구조 게이트가 진짜 사진을 떨어뜨린다**: 같은 쌍 실측 눈 중심 이동 = IPD 대비 **2.65%** · 밝기차 0.013. 현행 `landmark_align_pct: 2.0` 이면 레퍼런스 자체가 탈락이다. 합성을 끄면 정렬 허용을 같이 풀어야 한다(후보 4%). ⚠ 표본 1쌍 — 나머지 2쌍(lifting)도 재고 확정할 것.

(a) 로 가면 얼굴이 딴사람으로 흐르는 건 동일인 게이트(identity)가, 구도 붕괴는 구조 게이트가 잡는다. 합성이 막아 주던 "시술 부위 밖 이목구비 변형"은 지금 전용 자가 없다 — 필요하면 유사변환 정렬 뒤 팔자 밖 랜드마크 편차를 재는 자를 새로 둔다(덮어쓰기 대신 측정).

## 2. After 에 스타일 참조 — 가능. 단 선결 2개

- **API**: OpenAI `/images/edits` 는 입력 이미지 최대 10장, 마스크는 **첫 장**에만 적용(공식 가이드). `edit()` 에 `style_refs` 를 받아 Before 뒤에 `image[]` 로 붙이면 된다 — `generate()` 가 이미 같은 모양으로 보낸다.
- ⚠ **선결 A — 임상 기본 공급자가 실행 불가**: `providers.yaml` 임상 = gemini, `GeminiProvider.generate/edit` 는 `NotImplementedError`. 지금 실생성하면 Before 첫 콜에서 멈춘다. 당장은 `--gen openai --edit openai`(=Gemini 임상 전용 여부 결정과 한 벌).
- ⚠ **선결 B — 참조 고르기가 리그를 모른다**: `refs._rank` 는 lighting·quality·background 만 점수화. `blue_backdrop`·`clinic_wall` 참조는 태그가 똑같아 섞이고, 팔자는 Before 참조가 grey_studio 1장뿐이라 **어떤 리그를 뽑아도 회색 스튜디오 사진이 붙는다**(현재 Before 에도 해당). `samples_index.yaml` 에 `rig` 태그 + `_rank` 가 `variation["rig"]` 를 점수화해야 "세트마다 리그 고정"이 참조에서도 지켜진다.
- 참조는 남의 얼굴이다 → After 에 붙이면 동일인 점수가 내려갈 수 있다. 붙일 거면 같은 리그의 **After 시점 참조**만, 문구는 "조명·배경·질감만 참고, 얼굴은 1번 사진". 켜기 전후 identity 코사인을 같은 seed 로 비교해 판정.
- 참고(미실측): OpenAI 마스크는 알파 채널이 필요한데 `_png(mask_img)` 는 L 모드 PNG 를 보낸다. 임상을 GPT 로 돌리면 마스크 편집에서 400 또는 무시될 수 있다 — 첫 실회차에서 확인.

## 2차 (같은 날) — 리프팅 2쌍 재측정 + After 참조 구현

### 정렬 4% 재측정 (3쌍)

| 쌍 | 정렬 오차 | 밝기차 | 얼굴 크기 비율 | 믿을 만한가 |
|---|---|---|---|---|
| nasolabial_01 (grey_studio) | 2.65% | 0.013 | 0.003 | 예 |
| lifting_01 (blue_backdrop) | 2.07% | 0.014 | 0.010 | **참고치** — 코 아래 컷이라 눈이 프레임 밖, MediaPipe 가 눈 좌표를 지어냈다 |
| lifting_02 (clinic_wall) | 3.59% (오른쪽 맞춤) / 14.8% (왼쪽 맞춤) | 0.037 | 0.002 | **추정** — 전·후 가로 폭이 282 vs 309px(원본을 다르게 잘랐다). 화면상 머리 위치가 비슷해 3.59% 로 읽음 |

결론: **4% 유지.** 믿을 수 있는 값 중 4% 를 넘는 쌍이 없다. 다만 다른 날 촬영이 3.59% 로 여유가 얇다 — 실회차에서 '진짜 같은데 정렬로 탈락'이 나오면 5% 후보. 밝기(0.05)·얼굴 크기(0.03)는 3쌍 모두 넉넉히 통과.
lifting_02 도 (b) 합성에서 얼굴 왼쪽 테두리 이중 윤곽이 또 보였다(합성 끄기 판단 재확인).

⚠ 곁가지 발견: **부분 크롭 컷에서 MediaPipe 가 프레임 밖 눈을 지어내 `detect()` 가 None 이 아니다.** 구조 검사 머리말은 '부분 크롭 = 미검출 = 못 잼'을 전제하는데, lifting_01 같은 코 아래 컷은 가짜 눈 좌표로 정렬을 잰다. 지금 임상 리그는 정면 얼굴 전체라 급하진 않지만, 코 아래 프레이밍이 임상에 들어오면 정렬 게이트가 헛값으로 판정한다.

### After 스타일 참조 구현

- `OpenAIProvider.edit(image, prompt, mask, style_refs)` — 입력 순서 = Before 먼저, 참조는 뒤(마스크는 첫 장에만 걸림), 최대 10장.
- 마스크: `alpha_mask()` 가 우리 L 마스크(흰색 = 편집)를 RGBA(투명 = 편집)로 바꿔 보낸다. **문서 근거, 실호출 미측정** — 첫 실회차에서 편집이 팔자 쪽에 걸리는지 눈 확인.
- `batch.py` 임상 edit 경로가 `refs.pick(after_variation, when)` 로 **같은 리그·같은 시점 After 참조**를 골라 넘긴다. 맞는 참조가 없으면 빈 목록 = 종전 1장 편집(문구도 안 붙음).
- 참조가 붙을 때만 `config/prompts/edit_style_refs.md`("1번 사진을 고친다, 나머지는 배경·조명·카메라 느낌만, 사람은 절대 베끼지 않는다")를 After 프롬프트 끝에 더한다.
- 스위치: `clinical_rig.yaml` `after_style_refs: true`. 첫 실회차에서 켠 것/끈 것 동일인 점수를 같은 seed 로 비교.
- 현재 참조 재고로 실제로 붙는 조합: grey_studio 팔자 2주 · blue_backdrop 리프팅 2주·4주 · clinic_wall 리프팅 4주. 팔자 직후·1주, 리프팅 직후·1주는 참조 0장(종전과 같음).
- 회귀: selftest 4개 추가(마스크 알파 뒤집기 · 호출에 나가는 순서 · 나가는 마스크가 RGBA · 배치가 참조를 실제로 넘김).
