# 생성 이미지 사용 정책

상태: **확정 · 2026-09-10 파트장 결정 — 사용 범위 = 내부 참고용만**
(종전 2026-09-07 "임시: 전부 오픈"을 대체한다)

## 결정

- 생성물(전후 사진·파생 얼굴·씨앗)은 **회사 내부 참고용으로만** 쓴다.
- **금지**: 광고·SNS·홈페이지·인쇄물 등 대외 게시, 고객 대상 자료, 의료광고 심의 제출, 외부 공유.
- 따라서 **'AI 생성' 표기·워터마크·보이지 않는 표식은 넣지 않는다.** 대외 사용이 없으므로 표식이
  요구되는 상황 자체가 없다. (반대로 정책이 ②표기 후 광고·③심의 제출로 바뀌면, 표식은 생성 시점에
  들어가야 하므로 **그때 만든 이미지부터** 적용하고 그 이전 분은 재생성 대상이 된다.)

## 그래서 코드에서 하는 일

- 생성 파이프라인에 제한 로직·표식 삽입은 **넣지 않는다**(오늘 기준 코드 변경 없음).
- 추적은 종전대로 `meta.json`(배치·프롬프트 버전·모델)에 남는다 — 정책이 바뀌어도 무엇이 언제
  만들어졌는지 되짚을 수 있다.
- **내보내기(zip)에는 `사용범위-안내.txt` 를 함께 넣는다.** zip 은 결과물이 이 시스템을 떠나는 유일한
  경로라, 파일만 받은 사람도 범위를 알 수 있어야 한다.

## 남아 있는 것

- **의료진 검토자 미지정**(2026-09-10 파트장 "확정되면 다시 공유"). 시술별 변화 지시문
  (`config/treatments.yaml`)은 여전히 의료진 검토 전 초안이다 — 내부 참고용 범위 안에서만 쓴다.
- 의료법상 치료 전후 사진은 광고 시 심의 대상이다. 위 정책이 ②·③으로 바뀌면 **법무 확인이 선행**이다.
