# 생성 이미지 사용 정책 (임시)

상태: **법무 가이드 수령 전 임시 정책 · 2026-09-07 결정 — 사용 범위 전부 오픈**

- 현 단계에서는 결과물 사용처(내부 참고 / 표기 후 사용 / 광고 심의 제출 등)에 제한을 두지 않는다.
- 법무팀 연결 후 별도 가이드를 받아 이 문서를 교체한다. 그 전까지 시스템은 제한 로직을 넣지 않는다.
- 단, 나중에 정책이 바뀌어도 추적이 가능하도록 **모든 결과물의 meta.json에 생성 정보(배치·프롬프트 버전·모델)를 남긴다.** 워터마크·표기는 가이드 수령 후 결정.
- 시술별 변화 지시문(`config/treatments.yaml`)도 의료진 검토 없이 모두 오픈 상태로 진행. 검토자는 추후 지정.

관련: 의료광고의 치료 전후 사진은 의료법상 제한·심의 대상이므로, 광고 집행 전에는 반드시 법무 확인이 필요하다는 점만 기록해둔다.
