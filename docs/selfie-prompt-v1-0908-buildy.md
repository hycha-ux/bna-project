## 2. 수동 테스트에서 확인된 것 (GPT·Gemini, 팔자)

- 페르소나형 Before로 팔자가 제대로 보임.
- 각도 유지됨. 단 "same angle"로 쓰면 로봇처럼 동일 → "이웃 각도 + 구체적 방향 지시"가 필요.
- "different clothes"만 쓰면 옷이 안 바뀜 → 구체적 옷·배경·머리를 문장 앞쪽에 박아야 함.
- 잔머리가 레퍼런스에서 그대로 복사됨 → 프롬프트로 절반 정도 완화.
- 직후 컷에서 뾰루지 위치가 매번 달라짐 → 피부 상태 잠금 문단 추가.
- 처음 쓴 Before가 너무 극적으로 나쁨 → 강도 3단계.

## 3. 티모 확인 항목

1. **부분 크롭 vs 동일인 검증**: 코 아래만/한쪽 볼 프레이밍이면 `identity_lock.md`의 "same eyes"가 모순이고 InsightFace도 못 봅니다. (a) 프레이밍별 identity 문장 분기, (b) 동일인 기준을 코·입·턱 구조로 축소, (c) 레퍼런스처럼 눈 모자이크 후처리 — 셋 중 어느 조합으로 갈지.
2. **잔머리·결점 복사 문제**: After 생성 시 레퍼런스를 얼굴 영역만 크롭해서 넣으면 얼굴 밖 픽셀 복사가 줄 것 같습니다. 파이프라인에서 가능한지.
3. **직후 컷의 딜레마**: "각도 살짝 다르게"와 "결점 위치 동일"은 `composite_outside_mask`(같은 각도 전제)와 충돌합니다. 직후 컷만 각도 고정으로 갈지.
4. **After 드리프트 맥락 조합**: 배경·맥락이 독립 샘플이라 "차 안 + 수건 헤어밴드" 같은 조합이 나올 수 있음. 배경별 허용 맥락 표 필요.
5. **강도–효과 짝**: mild Before에 "noticeably shallower"는 과함. before_severity ↔ effect_level 매핑 규칙.
6. **팔자 마스크 C3 교체**는 이 문서와 무관하게 lang-ab-0907 §5대로 진행. 재확인 세트에 부분 크롭·측면 반드시 포함 요청.
