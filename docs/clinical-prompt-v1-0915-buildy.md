# 임상 프롬프트 1차 (빌디, 2026-09-15)

요청: 성연서님 — "임상사진은 같은 배경, 같은 조명인 게 특징. 근데 이목구비의 미세한 주름, 헤어스타일의 잔머리가 살짝씩 다른 거, 이런 게 특징으로 자리해야 해."
근거: 레퍼런스 3장 — ① 회색 배경·스튜디오 조명(서구) ② 파란 배경·병원 플래시, 다른 날이라 옷·목걸이 다름 ③ 병원 벽·천장등·로고 헤어밴드, 두 달 차, 눈 모자이크, 시술 후 볼 발적.
셀카 1차(0908)와 같은 방식으로 config + spec.py 를 고치고 dry-run 으로 눈 확인까지. 실생성은 안 돌렸습니다.

---

## 1. 임상 사진의 규칙 (레퍼런스에서 뽑은 것)

| 같아야 하는 것 | 살짝 달라야 하는 것 |
|---|---|
| 배경, 조명 위치, 카메라 거리·높이, 프레이밍, 정면 각도, 무표정 | 머리 위치 몇 mm·1~2도, 어깨 위치, 잔머리·헤어라인, 무표정의 결(눈가·입가 미세 주름), 노출 한 끗 |
| 직후면 옷·머리도 같음 | 다른 날이면 **옷은 다름**, 머리는 대략 같음 |

핵심: 종전 After 규정 "Keep identical framing, head position, expression, headband, gown…"은 **복사본**을 시켰다. 진짜 임상 사진은 같은 부스에서 **따로 찍은** 사진이다.

## 3. 티모 확인 항목

1. **`composite_outside_mask` 와 정면 충돌** (제일 큽니다). `batch.py` 가 임상 After 에 마스크 밖 Before 픽셀을 그대로 덮어씁니다. 그러면 잔머리·옷·머리 위치가 Before 와 **픽셀 동일**이 되어 이번 규정이 전부 지워집니다. 후보: (a) 임상에서 composite 끄고 동일인·구조 게이트로만 잡기 (b) 얼굴 안쪽(눈·코·입 영역)만 복원하고 머리·옷·배경은 모델 출력 유지 (c) 다른 날 컷만 끄기. 저는 (b) 가 규정과 제일 맞다고 봅니다.
2. **구조 게이트 임계**: 정렬 2%·밝기 0.05 는 그대로 뒀습니다. 리그 3벌 + "노출 한 끗 다름" 으로 탈락이 늘면 luma 0.08 까지가 후보.
3. **Gemini 임상 전용 여부**: 구조 v2 때 남은 결정. 리그 3벌은 edit 경로 전제라 생성기가 바뀌면 다시 봐야 합니다.
4. **안경**: 성연서님 확인으로 임상 `extras` 에서 뺐습니다 (같은 날). 촬영 때 벗기고 찍는 규정.
5. **눈 모자이크·날짜 스탬프**: 레퍼런스 ③처럼 후처리로 얹을지. 프롬프트로는 안 넣었습니다(글자 금지와 충돌).
