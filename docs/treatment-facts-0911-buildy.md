## 카드 양식
| 항목 | 뜻 |
|---|---|
| 효과 시점 | 즉시 / 1~2주 / 4주 — 직후 컷을 최종 강도로 그릴지, 거의 안 바뀐 상태로 그릴지 |
| 부위 범위 | 어디서 어디까지 — 시술 문장이 "일부 구간만" 바꾸지 않게 |
| 직후 흔적 | 무엇이 어디에 — 이게 있어야 "진짜 직후 사진" |
| 직후 금지 | 있으면 안 되는 것 — 크림·거즈·붕대 같은 사고 방지 |
| 며칠 뒤 | 1~2주 컷의 상태 — 흔적 제거 여부, 멍 가능 여부 |

### 프롬프트·검수에 어떻게 연결되나 (티모 영역)
- `series_levels.immediate` → 이 시술은 `final` (붓기 문장만 추가)
- `after_change` → 범위 문장 추가: entire length of the fold, nostril → mouth corner, both sides evenly
- ~~패치 소품·문장~~ → 넣지 않는다(위 참고). 실물은 참조 사진으로만
- 검수 `effect_visible` → "주름 일부 구간만 바뀌면 감점" 검토
