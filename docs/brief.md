# 프로젝트 브리프 — 온리프 B&A 대량 생성 시스템

작성일: 2026-09-07 (v2) · 담당: 메디빌더 디자인 · 저장소: hycha-ux/bna-project

---

## 1. 한 줄 정의

시술과 모드를 고르면 **실제 사람이 찍은 것처럼 보이는 얼굴 클로즈업 Before/After 사진을 수백 장 단위로 자동 생산**하고, 검수를 통과한 것만 갤러리에 쌓아주는 시스템.

## 2. 세 가지 핵심 축

이 프로젝트의 성패는 아래 세 가지로만 판단한다. 나머지는 부수 기능이다.

| 축 | 정의 | 실패 기준 |
|---|---|---|
| **① 실사 클로즈업** | 얼굴이 프레임의 대부분을 차지하는 근접 사진. AI가 아니라 **사람이 폰이나 카메라로 찍은 것**처럼 보여야 함 | 한 장이라도 "AI 같다"는 첫인상이 들면 실패 |
| **② 임상 동일 조건** | 후기·임상용은 Before와 After가 **같은 구도, 같은 조명, 같은 카메라**로 촬영된 것처럼 보여야 함. 병원에서 촬영 부스에 앉혀 찍은 문서 사진의 규격 | 두 장을 겹쳤을 때 얼굴 위치·크기·조명 방향이 어긋나면 실패 |
| **③ 대량생산** | 사람이 한 장씩 프롬프트 만지는 방식이 아니라, **시술 × 변주 조합을 배치로 던져 수백 장을 자동 생산**하고 검수·정리까지 기계가 함 | 100장 뽑는 데 사람 개입이 필요하거나 결과가 서로 비슷비슷하면 실패 |

## 3. 왜 만드나

- 온리프 시술 콘텐츠(후기·광고·상세페이지·SNS)에 B&A 사진이 상시 필요. 실제 임상 사진은 동의·수급·품질 편차 문제로 물량이 안 나옴.
- 2026년 초 prompf(브랜드 프롬프트 대시보드)로 프롬프트 자동 조합은 검증. 그러나 (a) 결과가 텍스트라 사람이 외부 툴에 붙여넣어야 했고 (b) 화보용 스타일이라 B&A 리얼리티에 맞지 않았고 (c) 한 장씩만 다뤘음.
- 이번엔 **프롬프트 → 이미지 → 검수 → 저장을 배치로 닫는다.** 한 장 잘 뽑는 게 아니라 **잘 뽑히는 확률을 시스템으로 올려서 물량을 확보**하는 게 목표.

## 4. 산출물 정의

### 4-1. 두 가지 모드

| | 후기용 / 임상용 (`clinical`) | 셀카용 / 일반인 (`selfie`) |
|---|---|---|
| 용도 | 고객 후기, 임상 자료, 상세페이지 전후 비교 | SNS 후기, 일반인 셀카 톤의 광고 소재 |
| 촬영 조건 | **고정 리그**: 클리닉 촬영 부스, 정면/45°/측면, 링라이트 또는 소프트박스, 동일 카메라·초점거리·거리 | 변주: 생활 배경, 폰 각도, 다양한 조명·화소 |
| Before/After 관계 | 촬영 조건 100% 동일. 시술 부위만 변화 | 같은 사람, 같은 장면. 폰 각도가 살짝 달라도 허용 |
| 인물 | 무표정, 머리 뒤로 묶음, 노메이크업, 헤어밴드·환자 가운 | 자연스러운 표정, 일상 상태 |
| 프레이밍 | 얼굴 클로즈업 계열, 세부 구도는 자유 | 얼굴 클로즈업 계열, 세부 구도는 자유 |

### 4-2. 프레이밍
- 프레이밍은 **규격으로 고정하지 않는다.** 얼굴 클로즈업 계열 안에서 모델이 자연스럽게 잡도록 자유도를 준다. (규격을 좁히면 오히려 비슷한 구도가 반복되어 리얼리티가 떨어짐)
- 시술 부위가 프레임 안에 잘 보이는지만 검수에서 확인한다.
- 결과 비율: 4:5 기본(인스타 피드·상세페이지), 1:1·9:16 옵션.

### 4-3. 시술 목록 (우선순위)
1. 팔자주름 · 2. 스킨부스터 엠보 · 3. 코 프팅 · 4. 스킨 퀄리티(홍조, 모공) · 5. 리프팅 · 6. 필러 · 7. 인중

## 5. 리얼리티 설계 원칙 (축 ①)

AI 이미지가 "AI 같아" 보이는 원인을 역으로 뒤집는다.

| AI 티의 원인 | 우리의 대응 |
|---|---|
| 완벽한 피부, 밀랍 광택 | 모공·솜털·잡티·붉은 기·미세 비대칭 **유지를 명시**. 리터칭 금지 문구 |
| 스튜디오급 조명, 8K 화보 접미 | 품질 접미 제거. 실제 기기 특성(폰 화소, 노이즈, 기본 색보정) 명시 |
| 좌우 완벽 대칭, 정중앙 구도 | 자연스러운 비대칭, 살짝 어긋난 프레이밍 허용 (셀카 모드) |
| 손가락·머리카락 붕괴 | 손 없는 구도를 기본값으로, 손 포함은 옵션. 검수 항목으로 상시 체크 |
| 같은 얼굴 반복 | 인물 변주 축(나라·연령·성별)에 얼굴형·피부톤 세부 축 추가 |

검증 방법: 통과작을 실제 사진과 섞어 팀원에게 블라인드로 보여주고 구분율 측정. **구분율 60% 이하(찍기 수준)면 합격.**

## 6. 임상 동일 조건 설계 (축 ②)

"동일 조건"을 프롬프트 문장에 의존하지 않고 **구조로 보장**한다.

1. **촬영 리그 프로파일** (`config/clinical_rig.yaml`): 카메라·렌즈·거리·조명·배경·자세를 하나의 고정 세트로 정의. 임상 모드는 이 세트를 그대로 사용하고 변주하지 않는다.
2. **After는 편집으로만 생성**: Before 이미지를 입력으로 시술 부위만 편집. 새로 그리지 않으므로 얼굴 위치·크기·조명이 픽셀 수준으로 유지된다.
3. **정렬 검증**: 두 이미지의 얼굴 랜드마크(눈·코·입 위치)를 비교해 오차가 임계값을 넘으면 불합격. 사람 눈이 아닌 수치로 판정.
4. **시리즈 생산**: 같은 인물로 정면·45°·측면 3컷 세트를 한 번에 생성 (실제 임상 촬영 규격과 동일).

## 7. 대량생산 설계 (축 ③)

| 요소 | 설계 |
|---|---|
| **배치 단위** | 요청 = (시술, 모드, 목표 통과 수). 예: "팔자 · 셀카 · 통과작 50장" |
| **변주 설계** | 8축 조합을 무작위가 아닌 **라틴 방격 샘플링**으로 뽑아 배치 안에서 축이 고르게 분포. 같은 얼굴·같은 장면이 반복되지 않도록 조합 중복 금지 |
| **처리량** | 프로바이더 병렬 호출(동시 N건). 목표: 시간당 통과작 100장 이상 (모델 속도에 따라 조정) |
| **자동 재시도** | 검수 미달 시 같은 변주로 최대 3회 재생성. 3회 실패한 조합은 로그에 남기고 넘어감 |
| **비용 관리** | 배치 시작 전 예상 호출 수·비용 표시. 통과율 데이터로 "1장 통과에 평균 몇 번 호출"을 추적해 예산 산정 |
| **결과 정리** | 파일명 규칙 `{시술}_{모드}_{국가}{연령}{성별}_{id}_before|after.jpg`, 배치별 폴더, `manifest.csv` 자동 생성 |
| **중복 제거** | 통과작끼리 얼굴 임베딩 유사도 비교, 너무 닮은 인물은 하나만 남김 |
| **사람 개입 지점** | 배치 시작(1회)과 최종 갤러리 확인(선택). 중간엔 없음 |

## 8. 전작(prompf)에서 가져오는 것

> 로직 자산만. UI는 참고하지 않고 신규 설계.

- 레이어형 프롬프트 조합 공식 (구조만, 내용은 전면 교체)
- 허용 풀 + 금지 목록 개념 → 모드별 제약으로 계승
- 온리프 브랜드 DB → 갤러리·후처리 톤 참고용

## 9. 범위

**포함**: 시술 8종, 모드 2종, 배치 생산·검수·정리, 갤러리, 모델 비교 스파이크, 얼굴 정렬·중복 검사
**하지 않는 것**: 프레이밍 규격 고정 (자유도 유지)
**제외**: 실제 환자 사진 편집(법무 별도), 좌우 합성 카드 디자인(디자인 자동화 파이프라인 담당), 타 브랜드 확장(구조만 열어둠)

## 10. 성공 기준

| 지표 | 목표 |
|---|---|
| 블라인드 실사 구분율 (통과작 vs 실제 사진) | 60% 이하 |
| 자동 검수 통과율 (팔자·셀카 기준) | 60% 이상 |
| 임상 모드 얼굴 정렬 오차 | 눈 중심 기준 2% 이내 |
| 처리량 | 시간당 통과작 100장 이상 |
| 사람 개입 | 배치당 시작 1회 외 0 |
| 사용성 | BX·그로스 팀원이 문서 없이 배치 실행 가능 |

## 11. 리스크

- **광고 심의**: 생성 이미지의 후기 사용 표기 의무. 기획 단계 법무 확인 필수.
- **모델 편집 보존력**: After 편집 시 모델이 얼굴 전체를 다시 그려버리면 축 ②가 무너짐. 스파이크에서 최우선 검증.
- **셀카 모드 통과율**: 손·머리카락 실패로 낮을 수 있음. 손 없는 구도 기본값으로 방어.
- **다양성 붕괴**: 대량 생산 시 모델이 비슷한 얼굴을 반복하는 경향. 중복 검사와 세부 변주 축으로 방어.
